# Campus textures (CC0)

Downloaded from the Poly Haven files API, using the 1K variants. These files are
served locally, including the HDR sky, and require no third-party runtime request.

* `pavement.jpg`, `pavement-normal.jpg`: [Concrete Pavement](https://polyhaven.com/a/concrete_pavement), Charlotte Baglioni, diffuse and OpenGL normal.
* `grass.jpg`: [Grass Path 2](https://polyhaven.com/a/grass_path_2), diffuse.
* `sky.hdr`: [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky), Greg Zaal / Jarod Guest.
