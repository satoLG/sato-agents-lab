# Chat wallpaper sources

SVG paths downloaded from SVG Repo, distributed under CC0 as listed on each source page:

- https://www.svgrepo.com/svg/452661/robot-neutral
- https://www.svgrepo.com/svg/452659/robot-love
- https://www.svgrepo.com/svg/151019/game-control-doodle
- https://www.svgrepo.com/svg/140738/game-console
- https://www.svgrepo.com/svg/456198/computer-chip
- https://www.svgrepo.com/svg/9288/robot-hand-drawn-outline
- https://www.svgrepo.com/svg/27468/rocket-hand-drawn-outline
- https://www.svgrepo.com/svg/157945/star-hand-drawn-symbol-outline
- https://www.svgrepo.com/svg/166626/joystick

Robot Neutral and Robot Love belong to the Doodle Library hand drawn collection. The
wallpaper recolors the paths and adds a slight sketch displacement to the console
chip and joystick. The tile uses varied sizes, free rotations and seeded
scattered positions, with collision checks including the repeat seam. Original source files are preserved here. Regenerate the local tile with
`node tools/build-chat-wallpaper.mjs`. No icon is fetched from a CDN in the app.
