# folio-2025 reference

`static/js/home-grass.js` also adapts the jittered grid, single camera-facing
triangle per blade, variable terrain height and tip-only wind from
https://github.com/brunosimon/folio-2025/blob/main/sources/Game/World/Grass.js
(Copyright 2025 Bruno Simon, MIT; see LICENSE.txt). The WebGL implementation
uses local terrain/water masks and reduced blade density for touch devices.
