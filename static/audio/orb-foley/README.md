# Orb footstep recordings

JDSherbert — Footstep Foley SFX Pack (FREE), archive supplied by the site owner.
These ten mono MP3 files are copied unchanged; `manifest.json` records the
original paths, sizes and SHA-256 checksums. No other pack content is shipped.

Grass → grass; Sand → sand; Stone → rock; Puddle → shallow water;
Water → deeper water. Each surface alternates two recordings. Takeoff and
landing reuse these recordings with separate gain, rate and release settings.
The archive contains no standalone license document; this attribution records
provenance without assigning an unverified license to the recordings.
